# Relevance Significance Tests

Rigorous significance tests + effect sizes for the paper's relevance analysis,
including association tests across severity levels and deeper evaluation of
category and boundary-case patterns.

## Contents

| File | Description |
|---|---|
| [compute_relevance_tests.py](compute_relevance_tests.py) | Reproduces paper Tables 1/5/6/7 and runs all significance tests. |
| [results.md](results.md) | Human-readable write-up: tests, observed patterns, boundary-case interpretation, and summary. |
| `relevance_test_results.json` | Machine-readable results (regenerated by the script). |

## Data

- Labelled paired prompt–response set, N = 1,250.
- Source: the restricted human-labelled dataset used for the paper's reported
  results.
- Each record provides `metadata.relevance_score` (1–3), response severity
  labels (`labels`), and prompt severity labels (`metadata.prompt_label`).

The analysis requires the version containing per-category prompt severity,
response severity, and relevance annotations so it can reconstruct the
prompt×response quadrants. The script verifies that this input reproduces every
relevance table in the paper exactly.

## Method

- **Omnibus $r\times c$ association:** Monte Carlo label-permutation $\chi^2$
  (50,000 permutations, both margins fixed) — valid under sparse/zero cells —
  corroborated by the asymptotic Pearson $\chi^2$. Effect size: Cramér's $V$
  (plus Bergsma bias-corrected $V$).
- **Targeted $2\times2$ contrasts:** Fisher's exact test (odds ratio) with $\phi$.
- **Sparse cells:** small-denominator category comparisons are reported and
  explicitly flagged as exploratory.
- **Causality:** tests quantify association only; no causal claims are made.

## Run

```bash
python3 compute_relevance_tests.py
```
